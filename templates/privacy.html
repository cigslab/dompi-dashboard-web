Kebijakan Privasi

Informasi tentang data yang diproses saat kamu menggunakan bot dan dashboard Dompi.

Data yang diproses

Dompi memproses ID Telegram, nama, username jika tersedia, serta data autentikasi Telegram untuk mengenali akunmu. Data akun juga mencakup paket, masa berlaku Pro, tanggal bergabung, dan pemakaian pencatatan bulanan.

Dompi memproses transaksi yang kamu kirim: nominal Rupiah, jenis pemasukan atau pengeluaran, tanggal, kategori, dan catatan. Jika kamu mengirim foto struk, gambar dan hasil pembacaannya diproses untuk membuat catatan transaksi. Hindari mengirim informasi sensitif yang tidak diperlukan.

Tujuan penggunaan

Data digunakan untuk menyimpan dan menampilkan catatanmu, menyusun ringkasan dan analitik, memeriksa akses akun, serta menjalankan paket dan batas pemakaian. Hasil pembacaan struk dapat keliru; periksa dan koreksi sebelum mengandalkannya.

Penyimpanan dan keamanan

Data akun dan transaksi disimpan dalam database layanan. Akses API dashboard memerlukan autentikasi Telegram dan dibatasi pada pemilik data. Jaga keamanan akun Telegrammu; tidak ada sistem yang dapat menjamin keamanan mutlak.

Foto struk diunduh sementara untuk diproses dan proses bot berupaya membersihkan file sementara setelah selesai. Pesan dan foto di Telegram, hasil pemrosesan, serta log infrastruktur dapat memiliki masa penyimpanan berbeda. Dompi belum menetapkan jadwal retensi terperinci pada halaman ini; penghapusan catatan bukan janji penghapusan seluruh salinan di semua layanan.

Pihak ketiga dan infrastruktur

Dompi menggunakan Telegram untuk interaksi dan autentikasi, serta Railway untuk hosting dan database. Jika pembacaan struk lokal belum memadai, foto dapat dikirim ke layanan Google Gemini untuk membantu ekstraksi. Layanan tersebut memproses data sesuai ketentuan masing-masing.

Dashboard juga memuat aset dari penyedia eksternal, seperti pustaka grafik; penyedia dapat menerima metadata koneksi saat aset dimuat. Baca juga Kebijakan Privasi Telegram.

Koreksi dan penghapusan

Kamu dapat mengoreksi atau menghapus transaksi milikmu melalui fitur yang tersedia di Dompi. Menghapus transaksi tidak mengembalikan kuota pencatatan. Penghapusan akun menyeluruh belum tersedia melalui dashboard; tombol Hapus Data / Akun masih belum aktif. Menghapus chat Telegram tidak otomatis menghapus catatan di database Dompi.

Bantuan dan kontak

Buka bot Dompi di Telegram dan gunakan /help untuk bantuan penggunaan. Kanal kontak khusus permintaan privasi atau penghapusan akun belum tersedia di dashboard; halaman ini akan diperbarui saat kanal tersebut tersedia.

Perubahan kebijakan

Kebijakan ini dapat diperbarui mengikuti perubahan fitur dan pemrosesan data. Periksa halaman ini secara berkala untuk membaca versi terbaru.
